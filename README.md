TaskFlow

TaskFlow is a to-do list app that helps you organize tasks and stay productive.
This is my first coding project, built with help from AI as I learn web development.

Features
Add and delete tasks
Mark tasks as completed
Create and rename saved lists
Save tasks and lists using local storage
Drag and drop tasks to reorder them
Light and dark mode
Simple, modern interface

HTML
CSS
JavaScript
